# Jenkins Docker CI/CD Pipeline

## Project Overview

This project demonstrates a CI/CD pipeline using Jenkins and Docker.

The pipeline performs:

1. Source Code Checkout from GitHub
2. Application Build
3. Docker Image Creation
4. Docker Image Push
5. Deployment Preparation

## Architecture

```text
Developer
    |
GitHub Repository
    |
Jenkins Pipeline
    |
Docker Build
    |
Docker Registry
```
